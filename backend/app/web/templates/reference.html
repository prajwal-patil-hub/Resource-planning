The labels work is filed under

Every report groups by one of these, so what lives here decides what those reports can say. Two things worth knowing before you change anything:

Nothing is ever deleted. A client with thirty finished items cannot be removed without those thirty items losing their history, so retiring one only stops it being offered for new work. Every past record stays exactly as it was.

Rename rather than replace. If a client changes its name, rename it — the records point at the row, not the text, so every past report simply starts saying the new name, which is right because it is the same client. Adding a second client and switching to it splits one relationship's history into two halves, and then neither total is true.

Roles {{ roles | length }}

A role is a name plus a place in the hierarchy. Per ADR-002 roles are data and can be added here at any time, while what each level may actually do lives in code — so a new role picks an existing level rather than an arbitrary set of powers. What each level grants is spelled out below rather than left to be guessed at.
